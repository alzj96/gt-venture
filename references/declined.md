# 他不方便答：换成自查表

**什么时候读这份**：他在划边界——「这个不太好说」「别问了」「涉及别人」（「没答」三种里的「不方便」，见 [六问](six-questions.md)），或者 `pattern.py show` 提醒某一问他以前不方便答过。

## 用户不方便回答时：换成自查表

这是这个技能里少数几个"两边都能赢"的地方。

不方便答的问题往往正是最关键的那个——在编身份、合伙人靠不靠谱、启动资金是借的。硬问拿不到答案，只会让他不再来；跳过则丢掉最重要的判断。

**出路是把需要他说出来的问题，改成他自己对照的检查表。** 把两种情况的结论都摆出来，让他自己往上套：

> 这条我不问了。但有件事你自己对照一下：
>
> **如果她是公办在编**——教师〔2015〕5号第六条管的是"为他人介绍生源、提供相关信息"，"她手上有 40 个家长"作为获客渠道用直接踩线；教基厅函〔2018〕102号连"先免费做"这条退路也堵死。这条路封死，得换获客渠道。
>
> **如果不在编**——这两条不适用，但类目资质那套还是要办。
>
> 你不用告诉我答案，自己知道就行。

**诊断价值全部保留，用户不用暴露任何东西。** 比硬问好，也比跳过好。

条件不明时报告里怎么写：「视 X 而定。若 X 成立则 A，否则 B。这一条你自己核。」——**不要假设一种情况然后一路往下推**，那会让整份报告建立在一个你没验证的前提上。

记一次，让下次不必再撞：

```bash
python3 <技能目录>/scripts/pattern.py --workspace "$(pwd)" sensitive --step <N>
```

同一问累计 ≥2 次，第 0 步的 `show` 会提醒你——**下次直接用自查表开场，别再问一遍**。
