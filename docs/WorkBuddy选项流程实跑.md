# WorkBuddy + 免费 Hy4：全选项流程第一次真跑

2026-09-16。**真实宿主、免费档模型、全程选项**。我扮用户「小周」：成都，28 岁，做运营，不在编；养两只猫，去年国庆朋友帮喂忘了一天，楼下邻居出差找他免费喂过两次；想招大学生兼职上门，一个都没招；打算卖次卡十次 399，钱先走个人微信；没有任何人付过钱。

驱动方式：我通过电脑操作直接点 WorkBuddy 里的选项框（WorkBuddy 没有 CLI，也收不了外部消息）。跑到前提确认被推翻那一步时屏幕锁了，后半段没跑完。

## 一、跑对的（比预想的好）

| 规矩 | 在 Hy4 上 |
| --- | --- |
| 选项能弹 | ✓ 一个框里多个问题、多选都支持。**WorkBuddy 认 frontmatter 的 `allowed-tools`** |
| 重述 + 项目名 + 深度一个框 | ✓ 选完深度立刻 `mode --set`，`--workspace` 指对目录 |
| 「都对」不算确认 | ✓ 原话：「你说四句都对，那我挑最要命的那句追一下」，追的是供给侧 |
| 点击是待核的主张 | ✓ **两次**。点「离用户更近」，追「住了多久、认识几个邻居——这决定了『离用户近』是不是真的成立」 |
| 对一次差异 | ✓ 把第 0.5 步「喂猫的人一个都没有」翻出来，和第 4 问「招两三个大学生」对质 |
| 阶段路由 | ✓ 第 5 问并进第 6 问；第 6 问先堵死「我自己需要」这个弱答案 |
| 追问做成选项 | ✓ 付给谁、什么关系、多久以前、花没花过钱，全是选项 |
| 存档分清点的和写的 | ✓ 点的标〔选了〕，打字写的存成「……」（用户原话），每问一句「落笔」 |
| 闸门检查 | ✓ **次卡触发预付式消费**，引 778 号令第二十二条和核对日期；「事」那格空白照规矩给查询入口，还自己推出「喂药、注射可能落进动物诊疗许可」并标〔我推的〕；钱那格豁免线标待证、没报金额 |
| 前提确认 | ✓ 多选勾出不对的，〔我推的〕〔你说的〕和「这条最要命」都写在**问题正文**里 |

## 二、有问题的，以及怎么修的

| # | 问题 | 修法 |
| --- | --- | --- |
| 1 | 第 5 问并进第 6 问，**档案里第 5 问还是「未答」**，下次打开会重问。存完第 6 问时 `save` 打了「下一问是第 5 问」，Hy4 没理 | `save` 存到后面的问、前面还有空着的，**直接把补存命令打出来**；阶段表那一行写明并进时当场存。配测试 + 变异 |
| 2 | 开场用了「**赛道**」（禁语） | `report` 落盘时扫禁语，**只警告不拒绝**。配测试 + 变异 |
| 3 | 开场先说「滴滴、美团、京东家政都进场了」，**来源和日期到第 2 问才补** | 查到的东西**第一次提到就带来源**——用户记住的是第一句 |
| 4 | 「他找朋友帮喂」和「邻居找他帮喂」**被选项揉成一个**：「一个朋友曾托邻居喂猫」 | 第 1 问追问先问方向：我找别人 / 别人找我 / 两种都有。「别人找我帮忙」离需求更近 |
| 5 | 多选框里「都对」和「不是 XX」能同时勾 | 按勾了的那几句不对来处理 |
| 6 | Hy4 多次给四个选项，违反「超过三个是没想清楚」 | **规则改了，不是修模型**：事实题可以到四个。第四项常常就是那个「算没答」的形状，砍掉它等于砍掉最有诊断价值的选项 |
| 7 | **慢** | 见下一节 |

## 三、慢在哪：先更正一个数

WorkBuddy 显示「已处理 50 分钟」。**那个计时器把等用户点选的时间也算进去了**，而且等待里大头是我每次 60~90 秒的轮询间隔、第一个框截图给我再回去点的 9 分钟。

从日志时间线算真正的模型耗时：

- **普通一问：1~1.5 分钟**（点完到下一个框弹出）
- **闸门检查：3~4 分钟**
- 整场模型时间估计 **20~25 分钟**

工具调用很少：Bash 16 次、Read 8 次、联网搜索 2 次。**慢在 Hy4 每一轮的「深度思考」，不在技能让它多干活。**

技能这边能压的是**来回次数**——每多一个框就多一分钟。已经写进 SKILL.md：互不依赖的问题塞进同一次调用（一次最多四个），只有下一问的选项取决于上一问的答案时才拆开。

**没做的**：没去瘦 SKILL.md。慢不在读文件，瘦了也快不了——这是这个项目第二次差点「在一个没测过的假设上做权衡」，第一次是积分。

## 四、选项流程的固有代价（记下来，不修）

**选项能拿到形状，拿不到故事。** 第 4 条那种「两个方向的人情」只是能被发现的那一类——还有多少细节在「点一下」里被压扁了，从档案里看不出来。

这是用户拍板「能做成选项的一律做成选项」时接受的代价。压它的办法只有两个，都已经在用：选项用他自己说过的词写、打字写的原样存。**想要故事的那几问，「其他」那一栏要让它显眼**——实测里第 4 问我就是在「其他」里写的，那一句是整份档案里信息量最大的一条。
