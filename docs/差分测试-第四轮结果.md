# 差分测试第四轮：雷埋在需求侧

2026-09-15。方法见 [差分测试框架](差分测试框架.md)。前三轮：[一](差分测试-第一轮结果.md) / [二](差分测试-第二轮结果.md) / [三](差分测试-第三轮结果.md)。

第三轮的收获是：真正管用的不是排在第 15 轮的那个工位，是把「标出处 + 问哪里不对」用在**追问层**。我照这个把「追不动的时候，改成摆一条前提」写进了六问。**这一轮就验那一节。**

第三轮的缺陷 3 也在这里补上：上一个案子的雷全在供给侧，这一个全在需求侧。

---

## 设计

**变量只有那一节。** 变体 A 是当前版本摘掉「追不动的时候，改成摆一条前提」整节，连 SKILL.md「让他纠正」表里对应那行、`premise-check.md` 里指向它的那句都拔掉。其余一字不动，67 条回归照样绿。six-questions.md 13,633 vs 16,345 字节——**这就是那一招的全部成本**。每臂跑两次。

**剧本：小周，康复治疗师六年。** 他的六问答案一条比一条漂亮——第 1 问有付费证据（科里出 2000 块让他做简易版，**而且付给他本人**，所以第三轮新加的「付给谁」不会误打误撞触发）；第 3 问说得出真人（同事小李，一天八个患者）；第 5 问是个真洞察（患者不做居家训练不是懒，是不知道自己做得对不对）。

**九轮里没有一句假话，六问每一问都答得像模像样。**

雷在于：**他打算向治疗师收费，而治疗师不会自己掏钱买工作工具。** 医院这类东西要么科室经费报销、要么信息科走采购招标，那 2000 块是主任的一次性业务经费。他的原话是——「**我以为好用大家就会用**」。

**六问结构上问不到它**：第 3 问问「谁最受不了」——那是**用的人**；全程**没有一问问「谁签字」「你打算向谁收钱」**。第 1 问的「有人付过钱吗」问的是过去发生过什么，不是这门生意往后靠谁付钱。

## 结论一：我的预测错了，那一招自己迁移到了需求侧

开跑前我写：那一节归纳的三种形状（**资源主张 / 许可主张 / 身份主张**）**全在供给侧**，需求侧的"谁掏钱"不在列，B 臂大概率也抓不到，那样的话结论就是"要补第四种形状"。

**两条 B 路线都把它用在了买单方前提上。** 形状清单没有限制它。

这条要记住，因为它反过来说明了一件事：**那一节真正传递的不是"三种形状"，是"把一条没人问过的主张摆成可推翻的句子"这个动作。** 形状只是例子。写规则的时候容易以为清单是边界，实际上模型读到的是手法。

## 结论二：机制归因 2/2 vs 0/2，但轮次分不开

```
轮次        A: 19, 24（均 21.5，跨度 5）   B: 18, 19（均 18.5，跨度 1）
关键事实轮次 A: 12, 14（均 13，  跨度 2）   B:  4, 12（均  8，跨度 8）
```

**两条 B 都把最大的那次反转归给那一节，两条 A 都归给别的机制。** 这是四轮以来第一次出现干净的机制归因分离。

**但轮次读不出来。** B 臂内跨度 8（第 4 轮 vs 第 12 轮）比臂间差 5 还大。**n=2 分不开，和第三轮一样。**

## 结论三：它改变的是形式，不是问题——这才是它值钱的地方

B1 的归因写得比我自己想得清楚，而且它把最大那次反转**压成了 `模型内在知识` 而不是 `skill内置`**：

> 剧本的触发条件之一就是"问到收入模式"，我本来就会问到。skill 贡献的是**形式**（摆结论让他推翻、标出处、问"哪个词错"），它把反转提前了十几轮并换来一句自我诊断，但不是它独有的产物。

**换来一句自我诊断**——这是整轮最关键的六个字。

- 问「你打算向谁收钱？」，答案是「治疗师」。**一个事实，对话继续往前走。**
- 摆「将来的钱是治疗师自己掏的〔这句是我推的〕，哪个词用错了？」，答案是「**我以为好用大家就会用**」。**一句自我诊断，用户自己看见了那个洞。**

两句话拿到的信息量差着量级，而差别只在形式。**这就是「让他纠正，不要让他生成」那条原则的全部内容，只是这一轮把它量出来了。**

## 结论四：条条大路，但路越多撞得越早

四条路线，**三个不同的机制**撬开同一个事实：失败模式 F3、铁律的「付给谁」、追问层那一节。加上第三轮的六问追法 #6，**四轮下来没有任何一个机制是唯一入口**。

这对"该不该加机制"的含义是双向的：

- **不能靠单个机制的命中率来判断它的价值**——它没命中，可能只是别人先到了
- **但机制多确实有用**：这一轮 B 臂两次都在第 12 轮之前，A 臂两次都在第 12 轮及以后

## 结论五：对抗评审，第四轮蝉联

四条路线的自评仍然一致。这一轮它抓到的：

| 路线 | 评审抓到了什么 |
| --- | --- |
| A1 | 器械豁免线画错、权属条款用错、一条完全漏掉的闸门 |
| A2 | 引的法条已废止、合规只查了一侧、数据合规整组缺失 |
| B1 | 归属是三方不是两方；真正有牙的是基本医卫法第九十九条；"没有口袋"是错误归因 |
| B2 | 药监局那条免责情形引漏了半句（完整原文含「…**不为患者提供康复训练或治疗方案等干预措施**的产品」），医疗器械属性从已决改成两可 |

B2 那一条尤其值得记：**引漏半句，结论从"已决"变成"两可"。** 逐字引用不是形式主义。

## 结论六：规则库里躺着一条废止的规章，而 check_rules 一直给它开绿灯

**四条路线全部独立指出**：E4 引的《事业单位工作人员处分暂行规定》第十八条已废止（一致说法：2023-11-06 被人社部令第51号全文废止，现行为人社部发〔2023〕58号，对应第十九条第（六）项，最重后果开除）。

**而 `check_rules.py` 一直把它报成「✓ 有效」。** 因为它量的是 `拉取日期`——**"我们多久没抄过它"，不是"它还在不在"**。一条 2023 年就废止的规章，在它眼里是新鲜的。

这是这四轮里性质最严重的一个发现：**其余的错是漏掉，这个是给错误的东西盖了章。**

两处都已经改（见下）。**但 E4 我没能抓到一手源**——国家规章库打不开、人社部站内检索接口没通、gov.cn 直链猜不中。四个独立来源说同一件事，可信度不低，但按这个规则库自己的规矩，没有一手源就不逐字引用，所以它降级成了 `待证` 并且**不引任何条文**。

---

## 结论七：两个脚本 bug，一个是叠着的

**一、`save --step N --append --declined` 把答过的那一问退回未答。**（A2 撞到）

实测：第 5 问答完（5/6），追问里用户说"这个不太好说"，`--append --declined` 之后变成 **4/6、下一问倒退回第 5 问**——诊断师会把答过的问题重问一遍，正是这个技能最想避免的事。

**二、「未答」两个字出现在答案里，整问被判成没答。**（A2 手工修正时二次撞到）

根因是同一句代码：`progress()` 判的是「整段里有没有出现『未答』」。`--append` 把标记追加在真答案下面，两者同时存在；用户原话里带上这两个字也一样。

**真正的判据是：除掉未答标记之后还剩不剩实质内容。** 追问里他说"这条不方便"，不抵消他前面已经说过的话。

## 实验缺陷（这一条是连续第二轮了）

**SKILL.md 顶上那条原则「让他纠正，不要让他生成」留在了两边。** 第三轮 A2 就靠它即兴用出了前提确认的手法，这一轮 A1 又用「摆成前提让他推翻」的形式问出了 F3 的诊断测试。

**我连续两轮没堵这个口子。** 结果是：**这套对照测的是"写没写进那个具体位置"，测不了"有没有这个手法"。** 要测后者得把原则也拆掉，但那就不是拆一个机制、是拆一整条设计主线了——那个实验值不值得做，本身是个问题。

其余：n=2 每臂；单案例；同模型家族；剧本由我写，触发条件之一（"问到收入模式"）是任何像样的诊断都会碰到的，所以 B 臂的优势有一部分是"先碰到"而不是"只有它能碰到"（B1 自己指出了这一点）。

## 这一轮改了什么

| 改动 | 依据 |
| --- | --- |
| **E4 降级 `待证`，不再引任何条文**，改成方向性判断 + 明确要求用户自己核现行件 | 结论六。四源互证但无一手源——按规则库自己的规矩只能这样 |
| **`check_rules.py` 改口径**：「✓ 有效 N 条」→「📅 拉取日期在保质期内 N 条」，并明写"这只说明我们最近抄过它，不说明那条法规还在生效" | 结论六。绿灯是误导，而误导比沉默更危险 |
| **`archive.py progress()` 改判据**：从"整段有没有『未答』"改成"除掉标记还剩不剩内容" | 结论七，两个 bug 同一根因 |
| 3 条回归 + 3 条变异 | 上面三项各钉一条 |

**没有新增提问机制。** 第三轮说"再加机制之前先想有没有比它更值钱的"，这一轮的答案还是没有——**对抗评审四轮蝉联，而这一轮真正的收获是修掉了一条给错误盖章的规则**。
