# 《基准真相》渗透清单：渗了什么，什么故意没渗

2026-09-15。全文读了一遍（发布版 html，5.2 万字；v4 草稿 4.0 万字是它的源）。

**筛选判据只有一条**：**它能不能落到一次具体对话上，变成一个能问出口的问题。** 落不到的，再对也不渗——那会把诊断变成布道。

立场部分在 [ETHOS.md](../ETHOS.md)（四条，每条带可证伪条件），操作部分在 [references/ai-era.md](../references/ai-era.md)（按需读）。

## 渗进去的

| 文章里的东西 | 落到哪 | 变成了什么问题 |
| --- | --- | --- |
| **距离判据**（一个 skill 的距离 vs 一段专有数据／一张牌照／一组物理资产） | ETHOS ②、ai-era ①、F9 | 「这件事写成一段提示词还剩什么？」 |
| **可托付税**（错误代价 × 漏检率 × 不可预测性） | ETHOS ③、ai-era ② | 「错了会怎样／看得出来吗／错的方式稳不稳定」，三句里有一句答不好，这门生意里必须站着一个人 |
| **可托付税 → 中国的具体形状** | ETHOS ③ | **这是全篇对这个技能最重要的一处**：高税的活需要人兜底，而在中国"需要人"往往具体成"需要一个有资质的主体签字"——**闸门检查不是合规附录，它是这条税在中国的形状** |
| **道德缓冲区**（担责保得住椅子，保不住坐椅子的人值多少钱） | ETHOS ③、ai-era ②、F16 出路一 | 给"有资质所以安全"扣一层：只能说「这是你暂时安全的位置」，不能说「这是你的护城河」 |
| **锯齿状边界**（758 人 RCT：边界外准确率从 85% 掉到 70%，且事先看不出） | ai-era ② | 「你的用户会不会在边界之外用它？他怎么知道自己出了边界？」 |
| **默会知识写不进文本** | ETHOS ④、ai-era ③、六问第 6 问 | 对传统行业的人反问：「你这行有什么是写不进文字的？」 |
| **填河的铲子握在河主人手里**（不被技术攻破，被流程填平） | ETHOS ④、ai-era ③ | 「现在有没有人在把它写成流程、录成视频、要求你交接文档？」 |
| **三条线：谁会留下** | ai-era ⓪ | 第三条以前完全没有：**「认知劳动价格趋近电费时，你的成本结构是受益方还是受害方」**——小生意常常两边都沾，净效果看他卖的那部分税高不高 |
| **认知层 vs 操作层横切所有行业**（制造业的认知层远比直觉厚） | ai-era ③ | 对传统行业用户的**双向**信息：能用的地方比你以为的多，会被冲击的地方也比你以为的多 |
| **具身三档相位曲线** | ai-era ③ | 「你这活儿在第几档」——给位置感，**不给日期** |
| **提问者经济的产出公式** + **放大器不创造信号** | ai-era ③.5、六问第 5 问 | 「被放大的那个信号是什么？」——"我会用 AI"是放大器不是信号 |
| **开放权重 3-4 个月时滞** | ai-era ③.5 | "我有 API／我会调模型"从来不是壁垒，那是所有人过几个月都会有的东西 |
| **梯子第一级被抽走**（22-25 岁在高暴露职业就业相对降 13%，资深者反升 6-13%；替代的正是大学教的书本知识） | 六问第 6 问的学生分支 | 三句话：这是信号不是定案／**"你没资源"很大程度不是你的问题，是梯子被抽了**／出路不是再去读点什么，是尽快拿一段写不进书里的经验 |
| **四种不可压缩的能力** | 六问第 6 问 | **反向用**：不拿它夸人，拿它对照——他说的优势落得进这四项吗？落不进的多半在射程内 |
| **被收割者的精确画像**（凡价值主张是"我替你处理繁琐复杂性"的生意） | F16 判据 | 旅游预订、保险被动续保 15-20% 保费、房产经纪 5-6% 佣金、支付通道 2-3% 交换费——小生意是同一形状，数字小 |
| **收割者也不安全**（模型层下场只需发一个 skill） | ai-era ④ | 判断收割者还是回到量距离那把尺子 |
| **微观 ground truth**（单位任务交付成本／单人产出倍数／毛利结构迁移） | ETHOS ①、ai-era 纪律三 | 「看账本，不看大势」——让他去测这三个数，比让他判断趋势有用 |

## 故意没渗的，以及为什么

| 没渗的 | 为什么 |
| --- | --- |
| 索洛悖论 2.0、幽灵 GDP、恩格斯停顿、劳动收入份额那组仪表盘 | **宏观判断，个体项目诊断用不上。** 一个开咖啡馆的人不需要知道货币流通速度 |
| 组织拓扑（轮辐结构、群体智能、企业级 AI） | 我们的用户是一两个人，**没有组织可重写** |
| Anthropic 组织标本、Palantir 奖学金 | **是例子不是判据**，而且文章自己给它们扣了幸存者偏差 |
| 供给侧瓶颈串（晶圆厂、先进封装、变压器、并网五年） | **投资判断，不是创业诊断。** 只在 ai-era 的「卖铲人」一行留了"越靠近扩不动的物理层越稳"一句 |
| AGI 时间表、三块拼图（世界模型／物理数据采集／新架构） | **我们不预言。** 时间表一旦写进技能，下一次模型发布就把它变成错的 |
| 汤森路透单日 −16% 那根 K 线 | 文章自己就警告过"拿价格波动讲故事"，并把结论降权成"市场**开始**定价、不是已经定准"。**我们更没有理由拿它当判据** |
| 13F 做空芯片股那个钩子 | 同上，文章自己拆了三句话说明它很可能被读反 |

**这一栏比上面那一栏更重要。** 一篇好文章里能用的东西远少于写得好的东西，而把"写得好"当成"用得上"渗进技能，结果是用户在诊断里听到一堂课——**他要的是一个能问出口的问题，不是一个世界观**。

## 有两处，文章改变了技能原来的说法

**一、「有资质所以安全」以前说得太满。** 加上道德缓冲区那一层之后，F16 的第一条出路（挪到兜底）和 ETHOS 第三条都改了口径：那把椅子能保住，坐椅子的人值多少钱是另一回事。

**二、「写不进文字的才是资产」以前是个静态判断。** 加上"填河的铲子"之后，它变成一个**带时限的**判断——护城河正在被谁填、填到哪了，是可以当场问出来的。这一改让第四条从一句安慰变成了一个动作。
